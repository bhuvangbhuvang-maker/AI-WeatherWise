# 🌤️ AI WeatherWise

**AI WeatherWise** is a smart weather information system that provides real-time weather information, intelligent weather advice, weather alerts, weather summaries, and a 5-day forecast for any city.

## 🚀 Features

- 🔍 Search weather by city
- 🌡️ Current temperature
- 🌡️ Feels-like temperature
- 💧 Humidity
- 💨 Wind speed
- 🤖 Intelligent weather advice
- ⚠️ Weather alerts
- 📝 Weather summary
- 📅 5-day weather forecast
- 📊 Temperature trend visualization
- 🔎 Recent search history
- 🗄️ MongoDB Atlas database integration
- 🌐 OpenWeather API integration
- 📱 Responsive web interface

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML | Web page structure |
| CSS | User interface and styling |
| JavaScript | Frontend functionality |
| Node.js | Backend runtime |
| Express.js | REST API server |
| MongoDB Atlas | Database |
| Mongoose | MongoDB integration |
| Axios | API requests |
| OpenWeather API | Weather data |
| Chart.js | Temperature visualization |
